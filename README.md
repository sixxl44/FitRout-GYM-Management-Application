# FitRout GYM Management Application
# CS351: Human Computer Interaction Project

## Overview

FitRout is a gym management application developed as part of the CS351 Human Computer Interaction course.

The project focuses on creating a user-friendly solution for managing gym memberships, attendance, workout schedules, and class bookings. The system was designed using Human-Computer Interaction principles with an emphasis on usability, accessibility, and efficient user interaction.

## Objectives

- Simplify gym membership and attendance management.
- Provide users with easy access to workout schedules and class bookings.
- Reduce reliance on manual processes and scattered records.
- Design a clear and user-friendly interface for different gym users.
- Apply Human-Computer Interaction principles throughout the design process.
- Evaluate the usability of the interface through user testing and feedback.
